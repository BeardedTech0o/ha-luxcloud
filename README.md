# LuxPower — Home Assistant Integration

[![HACS Badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://hacs.xyz)
[![Validate](https://github.com/BeardedTech0o/ha-solar-integration/actions/workflows/validate.yml/badge.svg)](https://github.com/BeardedTech0o/ha-solar-integration/actions/workflows/validate.yml)
[![GitHub Release](https://img.shields.io/github/v/release/BeardedTech0o/ha-solar-integration)](https://github.com/BeardedTech0o/ha-solar-integration/releases)

Monitor and control your **LuxPower** solar inverter and battery from Home Assistant.

---

## What you get

| Platform | Entities |
|----------|----------|
| **Sensor** | Solar power, battery power & SOC, grid import/export power, home load power, PV string voltages & currents, inverter & battery temperature, daily and lifetime energy totals (kWh), inverter status |
| **Switch** | AC charge on/off |
| **Number** | AC charge current limit, discharge cutoff SOC, charge cutoff SOC |
| **Select** | Work mode (Self-use / Feed-in Priority / Backup / Manual) |

All entities appear under a single **device** named after your inverter serial number.

---

## Requirements

- Home Assistant **2023.1** or newer
- A **LuxPower cloud account** — register free in the [LuxPower app](https://www.luxpowertek.com/app.html) (iOS / Android)
- Your inverter added to the app and connected to the internet via its WiFi/LAN dongle

---

## Installation

### Option A — HACS (recommended)

1. Open HACS in Home Assistant.
2. Click the **⋮** menu → **Custom repositories**.
3. Add `https://github.com/BeardedTech0o/ha-solar-integration` — category **Integration**.
4. Search for **LuxPower** and click **Download**.
5. Restart Home Assistant.

### Option B — Manual

1. Download the [latest release](https://github.com/BeardedTech0o/ha-solar-integration/releases/latest) zip.
2. Extract the `luxpower/` folder into your `config/custom_components/` directory:
   ```
   config/
   └── custom_components/
       └── luxpower/
           ├── __init__.py
           ├── manifest.json
           └── ...
   ```
3. Restart Home Assistant.

---

## Setup

1. Go to **Settings → Devices & Services**.
2. Click **+ Add Integration** and search for **LuxPower**.
3. Fill in the form:

   | Field | What to enter |
   |-------|--------------|
   | **Email address** | The email you use to log in to the LuxPower app |
   | **Password** | Your LuxPower account password |
   | **Inverter serial number** | Printed on the label on the side of your inverter (e.g. `2312XXXXXXXX`). Also visible in the app under *Device → Info* |
   | **Server region** | **EU** if you're in Europe (`eu.luxpowertek.com`), otherwise **Global** |

4. Click **Submit**. Home Assistant will verify your credentials and add the device.

> **Tip:** If you have multiple inverters on the same account, add the integration once per serial number.

## Entities reference

### Power sensors (live, updated every 30 s)

| Entity | Description |
|--------|-------------|
| `sensor.luxpower_SERIAL_solar_power` | Total solar generation in Watts. Positive = producing. |
| `sensor.luxpower_SERIAL_battery_power` | Battery power in Watts. **Positive = charging**, negative = discharging. |
| `sensor.luxpower_SERIAL_grid_power` | Grid power in Watts. **Positive = importing**, negative = exporting. |
| `sensor.luxpower_SERIAL_load_power` | Home consumption in Watts. |
| `sensor.luxpower_SERIAL_battery_state_of_charge` | Battery charge level (%). |

### Daily energy totals (reset at midnight)

| Entity | Description |
|--------|-------------|
| `sensor.luxpower_SERIAL_solar_energy_today` | kWh generated by solar panels today |
| `sensor.luxpower_SERIAL_export_energy_today` | kWh sent to the grid today |
| `sensor.luxpower_SERIAL_import_energy_today` | kWh taken from the grid today |
| `sensor.luxpower_SERIAL_battery_charge_today` | kWh charged into the battery today |
| `sensor.luxpower_SERIAL_battery_discharge_today` | kWh discharged from the battery today |

All energy sensors are compatible with the **Energy Dashboard** (`state_class: total_increasing`).

### Controls

| Entity | Description |
|--------|-------------|
| `switch.luxpower_SERIAL_ac_charge` | Turn grid-to-battery charging on or off |
| `number.luxpower_SERIAL_ac_charge_current_limit` | Maximum AC charge current (0–80 A) |
| `number.luxpower_SERIAL_discharge_cutoff_soc` | Minimum SOC before the battery stops discharging (%) |
| `number.luxpower_SERIAL_charge_cutoff_soc` | SOC at which charging stops (%) |
| `select.luxpower_SERIAL_work_mode` | Operating mode: Self-use / Feed-in Priority / Backup / Manual |

## Energy Dashboard

Add these sensors to get a full picture in the HA Energy Dashboard:

- **Solar production** → `Solar energy today`
- **Grid consumption** → `Import energy today`
- **Return to grid** → `Export energy today`
- **Battery** → `Battery charge today` / `Battery discharge today`

## Automation example — forecast-based overnight charging

Charge the battery from the grid overnight when tomorrow's solar forecast is low:

```yaml
automation:
  - alias: "LuxPower: charge overnight if solar forecast is low"
    trigger:
      - platform: time
        at: "22:00:00"
    condition:
      - condition: numeric_state
        entity_id: sensor.solcast_forecast_tomorrow   # adjust to your forecast sensor
        below: 5                                       # kWh threshold
    action:
      - service: switch.turn_on
        target:
          entity_id: switch.luxpower_SERIAL_ac_charge
      - service: number.set_value
        target:
          entity_id: number.luxpower_SERIAL_ac_charge_current_limit
        data:
          value: 50
      - service: select.select_option
        target:
          entity_id: select.luxpower_SERIAL_work_mode
        data:
          option: "Self Use"
```

## Troubleshooting

**"Cannot connect"** — Check that your inverter is online in the LuxPower app. Try switching the region between Global and EU.

**"Invalid auth"** — Double-check your email and password. Note the password is case-sensitive. If you use social login (Google/Apple) in the app, you may need to set a password via *Forgot Password*.

**Entities show "Unavailable"** — The inverter may be offline (no internet, power cut). Check the app. Entities will recover automatically when it comes back.

**Data is stale** — The integration polls every 30 seconds. If your inverter has poor connectivity, increase the poll interval in `custom_components/luxpower/const.py` (`DEFAULT_SCAN_INTERVAL`).
